# TANGO

## How to Run the Scripts

### Prerequisites

1. Python 3.6 or higher
2. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

### Running `runDataGen.py`

1. Ensure you have the original dataset in the `dataset` directory with the name `train.csv`.
2. Run the script:
   ```bash
   python runDataGen.py
   ```
3. The script will generate augmented datasets and save them to `dataset/dataset_aug_train_all_new.csv`.

### Running `bertEval.py`

1. Ensure you have the augmented dataset generated by `runDataGen.py` in the `dataset` directory with the name `dataset_aug_train_all_new.csv`.
2. Run the script:
   ```bash
   python bertEval.py
   ```
3. The script will evaluate the quality of sentence augmentations and save the results to `dataset/BERTEval.csv`.

### Cleaning the Repository

1. Remove unnecessary checkpoint files from the `.ipynb_checkpoints` directory.
2. Delete the following files from the `dataset_Small` directory:
   - `dataset_aug_train_all_new-checkpoint.csv`
   - `dataset_aug_train_all-checkpoint.csv`
   - `dataset_train-checkpoint.csv`
   - `dataset_aug_train_all_1.csv`
   - `dataset_aug_train_all_new_clean.csv`
   - `dataset_aug_train_all_new.csv`
   - `dataset_aug_train_all.csv`
   - `dataset_train.csv`
3. Delete the `scraper.ipynb` and `scraper.py` files.
